# Security policy

This repository holds written rules and the workflows that check them, not a running service. A security problem here is
a rule that leads to an unsafe practice, or a flaw in a workflow or configuration file.

## Reporting a problem

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a
vulnerability** ([how it works](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)).
Please do not open a public issue for it. Include what you found, where, and how to reproduce it.

We acknowledge a report within a week and say what we will do about it. A fix is published with a note in the
changelog once it is released.

## Supported versions

Only the latest commit on `main` is supported.
